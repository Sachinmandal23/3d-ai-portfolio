# 3D AI-Powered Portfolio

A modern, high-performance full-stack web application featuring an interactive 3D sci-fi environment, responsive UI, and a robust backend architecture designed to showcase professional software engineering skills.

🔗 **Live Demo:** [https://sachin-fullstack.vercel.app](https://sachin-fullstack.vercel.app)

---

## 🚀 Features
* **Interactive 3D Sci-Fi Environment:** Built using Three.js and React Three Fiber to deliver an immersive visual experience.
* **Responsive Modern UI:** Crafted with React, Vite, and Tailwind CSS for seamless performance across desktop and mobile devices.
* **AI Integration:** Integrated AI chatbot and smart interface elements for enhanced user interaction.
* **Secure Backend Services:** Powered by a robust Spring Boot backend handling RESTful APIs and business logic.

---

## 🛠️ Tech Stack

### Frontend:
* **Framework:** React.js (with Vite)
* **3D Graphics:** Three.js, React Three Fiber
* **Styling:** Tailwind CSS / Modern CSS
* **State & Tooling:** JavaScript (ES6+), NPM

### Backend:
* **Framework:** Spring Boot (Java)
* **Architecture:** RESTful APIs, Microservices-ready structure
* **Database & Connectivity:** SQL, Hibernate/JPA

⚙️ Getting Started & Local Installation
To run this project locally, follow these steps:

1. Clone the Repository
Bash
git clone [https://github.com/Sachinmandal23/3d-ai-portfolio.git](https://github.com/Sachinmandal23/3d-ai-portfolio.git)
cd 3d-ai-portfolio

2. Run the Frontend
Bash
cd frontend
npm install
npm run dev

3. Run the Backend
Bash
cd ../portfolio-backend
# Run via your preferred IDE (IntelliJ / Eclipse / VS Code) or using Maven:
mvn spring-boot:run
